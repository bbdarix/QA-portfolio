
# SauceDemo — Manual QA Testing Project

## Overview

This project demonstrates hands-on experience
in manual software testing using SauceDemo,
a demo e-commerce web application.

The project covers the complete testing workflow:
test planning, test design, test execution,
result analysis, and test reporting.

## Application Under Test

**Application:** SauceDemo (Swag Labs)

**Website:** https://www.saucedemo.com/

**Platform:** Web

## Testing Scope

- Login and Authentication
- Product Listing and Sorting
- Shopping Cart
- Checkout
- Navigation and Logout
